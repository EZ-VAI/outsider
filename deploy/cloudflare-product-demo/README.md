# Outsider Stage 0.5 public demo

This page replays a privacy-projected causal chain from a sealed, real Claude
Agent Team canary. It does not simulate a database write, execute an agent, or
claim a customer production outcome. The browser recomputes the public evidence
artifact hash and verifies the ordered intervention stages.

Run locally:

```bash
npm run demo:serve
```

Deploy after `wrangler login`:

```bash
npm run demo:deploy
```
