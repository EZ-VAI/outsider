# Outsider 1.3.57

1.3.57 is a private-beta candidate that closes the real R3 Agent Team integration-clearance asymmetry found while evaluating 1.3.56.

## Changed

- A frozen red acceptance at either `Stop` or `TaskCompleted` now deterministically invalidates an `onTrack:true` clearance.
- A rejected integration clearance enters the existing same-intervention clearance re-diagnosis and correction factual-audit path instead of returning an unattributed denial to the worker.
- PreTool semantic disambiguation is unchanged; the deterministic contradiction applies only at terminal delivery boundaries.
