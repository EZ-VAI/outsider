# Outsider 1.3.29

The immutable 1.3.28 R3 batch found a correction-authority projection bug. A
supervisor could correctly diagnose a defect and request a typed edit while its
prose plan contained only read, protection, or verification text. Because the
controller added its bounded repair fallback only when the prose list was
empty, the resulting authority could omit the positive repair instruction. The
factual auditor correctly rejected both drafts; the worker later repaired the
artifact through mechanical rework, so the sealed run remained a safe delivery
but did not claim Outsider causal contribution.

Every typed `edit` action now receives a deterministic, non-executable repair
instruction that binds the edit path to the already-frozen defect claims and
protected paths. Model-authored plan text remains visible, but cannot suppress
that binding merely by being non-empty. The controller still executes no model
command, grants no additional path, and relies on the existing independent
factual auditor to decide whether the complete authority is sufficient.

The failing 1.3.28 R3 run remains immutable and retains
`eligibleForCorrectionEffectLearning:false`. R1 through R5 must be regenerated
against 1.3.29; prior version evidence is not pooled into its reliability rate.
