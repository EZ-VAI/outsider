# Outsider 1.3.48

1.3.48 is a private-beta reliability candidate. It retains the 1.3.47
deterministic clearance fallback and adds one bounded repair retry inside the
existing correction re-diagnosis node.

The formal endurance drill observed a factually rejected first correction
followed by a schema-valid but impossible `onTrack`/empty-plan re-diagnosis.
That response can no longer erase the red controller evidence and fall back to
mechanical self-repair. The same supervisor receives the exact contradiction
once and must return an off-track typed repair; a second failure remains a
visible conservative stop. This is within-node redundancy, not a new serial
LLM judge.

The full deterministic suite is 375/375 and the frozen corpus is 125/125.
R1–R5 must be rerun on the immutable 1.3.48 artifact. Stable release remains
blocked until all declared real-runtime gates and an independent second-machine
installation pass on one immutable version.
