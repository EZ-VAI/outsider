# Outsider 1.3.43

Private-beta Global Outsider protocol candidate. Runtime evidence from older
package hashes does not transfer to this artifact.

## Global provider-neutral plane

- Adds signed, privacy-safe Way attestations for Claude, DeepSeek Harness,
  Codex, Trae, deterministic programs and durable workflows.
- Adds live signed checkpoint chains and a durable global monitor that reports
  blocked, stale, delivery-ready and terminated provider runs without taking
  local execution authority.
- Adds two-party handoff signing. The sender creates an offer; the receiver
  verifies it and creates a receipt on a different machine. A coordinator never
  needs both companies' private keys.
- Adds a content-addressed global registry with packet deduplication, nonce
  replay rejection, tenant-scoped reads, restart-time signature verification
  and tamper refusal.
- Preserves D1 disclosure, D2 instrument/version cohorts, correlation-component
  upper bounds and the explicit statement that keys/configuration do not prove
  institutional independence.

## DeepSeek and learning data

The pinned DeepSeek Harness adapter remains capped at durable delivery plus a
bounded deterministic post-delivery action effect. It still cannot declare a
semantic outcome. Codex and Trae remain observer-only. Claude can project its
sealed Stage 0.5 evidence, but only a conformant local Claude run receives the
controlled claim.

Each verified cross-provider packet produces one
`outsider/federated-supervision/v1` record. Monitor snapshots and final packet
summaries are admitted by the sibling Outsiderf Stage 1 research corpus as
correlated routing/operations evidence only. They cannot enter correction
causal-effect, reliability-guarantee, incident/loss, PRICE, GUARANTEE or SETTLE
denominators.

## Verification and release boundary

The deterministic product suite and 125-case gate corpus must pass for the
immutable artifact. R1–R5, real Cowork conformance, multi-hour endurance and an
independent second-machine installation must be regenerated for 1.3.43 before
stable release. This source release does not claim those field gates passed,
does not establish a real four-company chain, grants no clearing authority and
moves no funds. Do not hot-upgrade an active controlled session.
