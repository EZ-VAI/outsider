## English — post-release short (only after the tag and artifacts exist)

Outsider Stage 0.5 is now packaged for Claude and as a universal ChatGPT/Codex
plugin. It adds an independent, local-first verification layer around agent
work: freeze the task, watch execution evidence, challenge false completion,
and separate “the output looks right” from “the intervention caused the fix.”

The honest boundary matters: Claude and Codex control still requires the
companion runtime, trusted hooks, and a real conformance receipt. The package
is structured for installation by eligible ChatGPT accounts and workspaces,
but live Desktop installation and new-chat evaluation are not yet established;
ordinary chats are not globally intercepted.
The tagged repo marketplace package is installable; public Plugins Directory
publication is a separate review step. Open-source beta, not a claim of
universal control.
