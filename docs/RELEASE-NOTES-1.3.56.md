# Outsider 1.3.56

1.3.56 is a private-beta candidate that fixes the evidence ambiguity exposed by the real R3 Agent Team gate.

- Ordered tool evidence now retains the host-bound actor id. A teammate edit can no longer be silently re-attributed to the lead.
- Semantic verifier and supervisor packets now include the controller's existing, hash-chained team identity, task ownership, file-effect, per-slice verification, completion, and integration events. No new model judge was added.
- Formal endurance now requires every teammate Agent call to explicitly request Sonnet. Missing, inherited, Opus, Fable, or Haiku selection is denied before the Agent can spawn and terminates the evaluation visibly.
- The prior aborted R3 run remains an immutable failed experiment. Its false team diagnosis and exhausted supervisor budget are not counted as a successful gate.

The release remains private beta. R1-R5 evidence must be generated against this exact immutable artifact; earlier versioned runs are historical evidence only.
