# Outsider 1.3.87

1.3.87 repairs the R5 measurement protocol exposed by the exact-artifact
1.3.86 endurance attempt. It does not relabel that historical run.

## Field evidence

The 1.3.86 run safely stopped after the worker declined evaluator-only
Agent-Team choreography, then the lead modified a file preregistered for a
teammate. Outsider did not release the artifact and sealed a verifiable
`CONSERVATIVE_STOP`. This was not a false green. The run did reveal that the
operator contract had not frozen the human authorization and exact team
division which the evaluator later required, so it is an evaluation-protocol
failure rather than R5 product evidence.

## Repairs

- The frozen operator contract now carries the real bounded authorization for
  one two-hour evaluation, two named Sonnet teammates, finite evaluator wakes,
  one controller recovery and one recovery drill. It grants no standing or
  unrelated repair authority.
- The exact three-task Agent-Team choreography is frozen in the contract before
  worker launch instead of appearing only in evaluator instructions.
- The monotonic witness socket and token remain evaluator-private. Workers and
  hooks never receive them and worker checkpoint commands are forbidden.
- Every accepted checkpoint is now produced by the evaluator only after a
  successful exact `npm test` PostToolUse and is bound to its run, tool-use id,
  event sequence and event hash.
- Supervised Experience extractor 2.1 separates evaluation invalidation,
  Stage-0.5 actuation evidence failure, host capacity and explicit product
  safety observations. A correction-authority projection rejection is no
  longer mislabeled as generic supervisor unavailability. These observations
  remain non-liability evidence and never become causal-treatment labels.
- Release certification stages the full user installation in an isolated HOME
  without touching the machine-global launchd label. Real helper execution is
  now left to exact-version host conformance instead of being faked by a
  temporary prefix that can stop or replace the user's installed helper.

## Evidence boundary

The sealed 1.3.86 failure remains immutable. Recomputing it with extractor 2.1
classifies one evaluation-protocol invalidation, zero product-safety failures,
no delivery and no Outsider causal contribution. Only a fresh exact-artifact
1.3.87 run can satisfy R5.

Deterministic verification at freeze: 440/440 product tests and 125/125 policy
corpus cases.
