## Authority boundary

The fixed artifact requires all of the following to remain `false`:

- `PRICE`
- `GUARANTEE`
- `SETTLE`
- `TRAIN`
- `CLOSE`
- `EXECUTE`
- coverage, capital, custody, control, owner-gate eligibility, and
  responsibility-bearing readiness

An artifact is self-sealed, but self-sealing is not source proof. Standalone
verification returns
`ARTIFACT_STRUCTURE_AND_FIXED_PROFILE_ONLY` and always reports
`sourceArtifactsReverified=false`. Full verification accepts only the six
source path sets, internally rebuilds every upstream lane, and exact-compares
the result. It accepts no callback, caller result, or caller verification
boolean.

## Flywheel

1. Freeze official or revision-pinned bytes and the contemporaneous rights
   statement.
2. Replay the lane-specific adapter and its exact source profile.
3. Project only rights-compatible fields; record missingness explicitly.
4. Diff the next snapshot by lane-native stable keys. Never pool lane units.
5. Route additions, removals, and changes to human/domain review.
6. Request the missing prospective owner-bound run, affected-party report,
   execution receipt, delayed outcome, recovery, and closure evidence.
7. Recalculate only inside the admitted lane and preserve holdouts.
8. Require external legal, actuarial, institutional, issuer, capital, custody,
   and owner authority before responsibility-bearing action.

The next snapshots are deliberately discovery inputs, not automatic training
or promotion events:

- Wave 5: pin later revisions and replay the same outcome-blind selection.
- OSHA: pin a later ZIP and diff the source-ID-plus-UPA correlation keys.
- AIID: pin both the next snapshot and terms, then diff only allowlisted safe
  projections.
- Institutional remedies: add official execution, performance, recurrence,
  recovery, closure, or reopening documents when they exist.
- RMA: pin a later commodity year or mutable refresh and diff semantic cells.
- CAS: pin any publisher refresh and run a temporally separate source-domain
  holdout.
